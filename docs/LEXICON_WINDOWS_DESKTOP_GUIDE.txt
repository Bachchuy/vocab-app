LEXICON WINDOWS DESKTOP - CÁCH CHẠY VÀ CÁCH LƯU DỮ LIỆU
========================================================

Mục đích
--------
Lexicon desktop là ứng dụng Windows đóng gói bằng Tauri 2. Giao diện vẫn dùng
React/TypeScript; Tauri tạo cửa sổ native và cho frontend sử dụng plugin SQLite.
NestJS backend được giữ cho chế độ web/API và dịch vụ gợi ý AI.

Kiến trúc đang chạy
-------------------
Tauri window -> React UI -> vocabularyStore -> Tauri SQL plugin -> SQLite local

Backend/API:
React web -> HTTP -> NestJS controller/service/repository -> Prisma -> SQLite

AI trong desktop:
React -> POST http://localhost:3000/ai/suggest -> NestJS -> OpenAI API.

CRUD/review desktop không cần backend. AI cần backend và Internet. Dữ liệu
desktop với backend database là hai kho riêng, hiện chưa đồng bộ tự động.
Chuyển JSON chỉ chuyển danh sách từ, không chuyển lịch sử ôn.

Tính năng desktop
-----------------
- Tạo, xem, sửa, xóa, tìm, lọc, sắp xếp từ.
- Các trường từ loại, phiên âm IPA, ví dụ và metadata TOEIC.
- Họ từ, synonym, antonym, collocations.
- Flashcard, lịch ôn cơ bản và thống kê dashboard.
- Nhập/xuất JSON từ vựng.
- Gợi ý AI nếu backend đã cấu hình.

Chạy desktop trong lúc phát triển
---------------------------------
Yêu cầu Node.js, Rust stable với MSVC toolchain, Visual C++ Build Tools,
Windows SDK và WebView2.

  cd D:\code\vocab-app\frontend
  npm ci
  npm run desktop:dev

Tạo app release không bundle:

  npm run desktop:build

Tạo NSIS installer:

  npm run desktop:installer

Installer đã tạo tại:

  frontend\src-tauri\target\release\bundle\nsis\Lexicon_0.1.0_x64-setup.exe

Database và bảo toàn dữ liệu
----------------------------
Desktop SQLite được plugin Tauri quản lý trong vùng dữ liệu ứng dụng của user;
đừng xóa database để xử lý lỗi trước khi sao lưu. Export JSON để sao lưu từ.
Review states/history hiện không nằm trong file JSON transfer.

Lần khởi động đầu, frontend tạo bảng cần thiết và thêm các cột mới nếu database
cũ thiếu chúng. Quyền Tauri capability gồm quyền SQL execute để insert/update/
delete có thể chạy. Khi phân phối phiên bản mới, build installer lại sau các
thay đổi frontend/capability.

AI
--
Tạo backend/.env từ backend/.env.example rồi điền OPENAI_API_KEY. Chạy backend
riêng ở localhost:3000. Không đưa key vào frontend hoặc package desktop. Xem
docs/TOEIC_AI.md để biết trường dữ liệu và giới hạn của gợi ý.

Điểm cần kiểm tra trước khi phát hành
------------------------------------
- Cài installer trên máy Windows và kiểm tra mở/đóng ứng dụng.
- Thêm/sửa/xóa từ và khởi động lại để xác nhận dữ liệu còn.
- Thử review và xác nhận due date/trạng thái.
- Thử nhập/xuất JSON.
- Xác nhận app core vẫn dùng được khi backend tắt.
- Khi bật AI, thử khóa thiếu/sai và lỗi mạng để thông báo rõ ràng.
- Tạo backup trước mọi thay đổi có thể làm mất dữ liệu.
