LEXICON V1 - KHỞI ĐỘNG NHANH TRÊN WINDOWS
==========================================

V1 là gì
--------
V1 là từ điển cá nhân chạy cục bộ trên trình duyệt. Ứng dụng dùng cơ sở dữ liệu SQLite thật thông qua backend NestJS. Dữ liệu vẫn còn sau khi khởi động lại backend vì được lưu trong SQLite của Prisma.

Vỏ desktop Tauri là một bản thử nghiệm riêng với cơ sở dữ liệu riêng; hiện chưa nhập hoặc đồng bộ cơ sở dữ liệu browser/backend.

V1 có
-----
- Thêm mục từ.
- Sửa mục từ.
- Xóa mục từ.
- Ngăn trùng cách viết.
- Lưu nghĩa, câu ví dụ, nguồn, ghi chú, chủ đề và metadata từ vựng.
- Tìm kiếm theo từ, nghĩa, ví dụ, nguồn và ghi chú.
- Lọc và sắp xếp từ điển cá nhân.
- Mở trang chi tiết của một mục từ.
- Ôn từ đã lưu với bộ lập lịch lặp lại ngắt quãng đơn giản.
- Lưu trạng thái và lịch sử ôn trong SQLite.
- Nhập và xuất bản sao lưu mục từ dưới dạng file JSON Lexicon.
- Chọn từng mục từ để xuất các trường từ vựng thành bảng tính Excel `.xlsx`.
- Mở **Quản lý dữ liệu** trên thanh bên để nhập/xuất JSON hoặc tạo bảng tính; JSON giữ định dạng Lexicon, Excel tiện xem và lọc.
- Dùng cùng REST API từ frontend React.

Yêu cầu
-------
- Windows 10 hoặc Windows 11.
- Node.js LTS.
- npm.

Khởi động V1 thủ công
---------------------
Mở cửa sổ PowerShell thứ nhất:

  cd D:\code\vocab-app\backend
  npm install
  npm run db:generate
  npm run db:migrate
  npm run db:seed
  npm run start:dev

Mở cửa sổ PowerShell thứ hai:

  cd D:\code\vocab-app\frontend
  npm install
  npm run dev

Mở địa chỉ sau trên trình duyệt:

  http://localhost:5173

API backend:

  http://localhost:3000

Tạo bộ cài Windows
------------------
Trong thư mục frontend, chạy:

  npm run desktop:installer

Bộ cài NSIS được tạo tại:

  frontend\src-tauri\target\release\bundle\nsis\Lexicon_1.1.1_x64-setup.exe

Ứng dụng desktop lưu từ vựng trong SQLite cục bộ riêng. Hiện chưa đồng bộ với cơ sở dữ liệu browser/backend. Chuyển đổi JSON mới chỉ nhập/xuất mục từ; lịch ôn vẫn nằm riêng trong cơ sở dữ liệu của từng ứng dụng.

Khởi động V1 bằng một script
----------------------------
Từ thư mục gốc của kho mã nguồn:

  powershell -ExecutionPolicy Bypass -File .\start-v1.ps1

Script sẽ cài dependency còn thiếu, chuẩn bị cơ sở dữ liệu Prisma, nạp dữ liệu mẫu cũ theo cách an toàn khi chạy lại và mở hai cửa sổ PowerShell. Giữ cả hai cửa sổ khi dùng V1. Muốn dừng V1, đóng hai cửa sổ đó.

Cơ sở dữ liệu
-------------
Cơ sở dữ liệu phát triển:

  backend\prisma\dev.db

Không xóa file này nếu muốn giữ dữ liệu từ vựng cục bộ. Không commit file này lên Git.

Kiểm tra nhanh
--------------

  cd backend
  npm run db:status
  npm run build

  cd ..\frontend
  npm run build

API ôn tập
----------

  GET  http://localhost:3000/reviews/due
  GET  http://localhost:3000/reviews/states
  GET  http://localhost:3000/reviews/:wordId/history
  POST http://localhost:3000/reviews/:wordId

Ví dụ nội dung review:

  {"rating":"easy"}

V1 chưa có
----------
- Nhập/xuất lịch sử ôn (file JSON hiện chỉ chứa mục từ).
- Xác thực và nhiều người dùng.
- Collection.
- Tra từ điển tự động và phát âm tự động.
- Đồng bộ đám mây.
- Một số tính năng AI nâng cao.
- Bộ kiểm thử tự động đầy đủ.

Các mốc tiếp theo đề xuất
-------------------------
1. Thêm test backend và test bộ lập lịch ôn.
2. Thêm quản lý collection và tag.
3. Hoàn thiện giao diện nhập nhiều sense và thông tin từ vựng mở rộng.
4. Thêm nhập/xuất JSON và CSV.
5. Thêm sao lưu/khôi phục lịch sử ôn và kiểm tra bộ cài trên máy Windows sạch.
6. Chỉ thêm đồng bộ đám mây sau khi quyền sở hữu dữ liệu cục bộ ổn định.

Dành cho trợ lý AI về sau
-------------------------
Đọc file này trước, sau đó đọc:

  docs\desktop\LEXICON_WINDOWS_DESKTOP_GUIDE.txt
  docs\development\ROADMAP_VOCAB_APP.md

Không viết lại dự án. Giữ V1 hoạt động trong khi thêm từng mốc một. Sau thay đổi, chạy build frontend và backend. Desktop dùng SQLite cục bộ; browser dùng backend NestJS/Prisma và hiện chưa đồng bộ với desktop. Có thể tạo lại bộ cài NSIS bằng `npm run desktop:installer` trong thư mục frontend. Xem ghi chú [phát hành 1.1.1](RELEASE_v1.1.1.md) và [hướng dẫn cập nhật installer](INSTALLER_UPDATE_GUIDE.md) để biết thay đổi, cách cập nhật và trạng thái kiểm tra.
