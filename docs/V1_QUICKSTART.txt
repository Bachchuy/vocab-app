LEXICON - QUICK START VÀ LUỒNG HOẠT ĐỘNG
========================================

Lexicon là gì
-------------
Ứng dụng từ điển cá nhân học từ vựng TOEIC. Người dùng lưu từ và ngữ cảnh,
chỉnh sửa nghĩa/họ từ/quan hệ nghĩa, ôn bằng flashcard, rồi xem thống kê cơ bản.
Có frontend React, backend NestJS, backend database SQLite/Prisma và app desktop
Windows Tauri dùng SQLite riêng.

Đọc hướng dẫn nhập môn
----------------------
txt/00_TONG_QUAN_VA_LUONG_HOC.txt giải thích kiến trúc và luồng dữ liệu theo
cách dành cho người mới học code. Tài liệu này tập trung lệnh thực thi.

Yêu cầu
-------
- Windows 10/11.
- Node.js và npm.
- Để build desktop: Rust MSVC, Visual C++ Build Tools, Windows SDK và WebView2.
- Để dùng gợi ý AI: OPENAI_API_KEY hợp lệ, Internet và backend đang chạy.

Chạy nhanh web ở môi trường đã cài dependencies
-----------------------------------------------
Từ PowerShell tại D:\code\vocab-app:

  powershell -ExecutionPolicy Bypass -File .\start-v1.ps1

Script cài dependencies còn thiếu, tạo/cập nhật Prisma Client, áp migrations,
nạp starter data và mở terminal backend/frontend. Mở http://localhost:5173.
Giữ hai cửa sổ chạy khi dùng web; đóng chúng để dừng server.

Chạy thủ công lần đầu
---------------------
Terminal 1 - backend:

  cd D:\code\vocab-app\backend
  npm ci
  npm run db:generate
  npx prisma migrate deploy
  npm run db:seed
  npm run start:dev

Terminal 2 - frontend:

  cd D:\code\vocab-app\frontend
  npm ci
  npm run dev

Mở http://localhost:5173. Backend mặc định http://localhost:3000. Kiểm tra API:
http://localhost:3000/words.

Chạy desktop
-------------
Đã build installer trong project tại:

  frontend\src-tauri\target\release\bundle\nsis\Lexicon_0.1.0_x64-setup.exe

Môi trường phát triển có thể chạy:

  cd D:\code\vocab-app\frontend
  npm run desktop:dev

Tạo installer mới:

  npm run desktop:installer

Desktop CRUD và review dùng SQLite local, không cần NestJS chạy. Nút gợi ý AI
cần backend chạy tại localhost:3000. Web dev thì dùng NestJS cho CRUD/review.

AI suggestions
--------------
Copy backend/.env.example thành backend/.env (nếu chưa có), đặt OPENAI_API_KEY
rồi khởi động lại backend. Khóa API chỉ backend đọc. Nút AI điền gợi ý vào form;
người dùng có thể sửa và phải bấm lưu. Hãy tự kiểm tra vì nội dung AI có thể sai.
Chi tiết: docs/TOEIC_AI.md.

Tính năng hiện tại
------------------
- Thêm, xem, sửa, xóa, tìm, lọc và sắp xếp từ.
- Nghĩa, từ loại, IPA, ví dụ, chủ đề TOEIC, họ từ, synonyms, antonyms,
  collocations, nguồn và ghi chú.
- JSON import/export danh sách từ vựng.
- Flashcard và review ratings again/hard/good/easy.
- Review states/history và lịch ôn cơ bản.
- Dashboard tổng từ, từ đến hạn, đã thuộc, hoạt động 7 ngày, chủ đề.

API chính
---------
Words: GET/POST /words, GET/PATCH/DELETE /words/:id.
Reviews: GET /reviews/due, GET /reviews/states,
         POST /reviews/:wordId, GET /reviews/:wordId/history.
AI:      POST /ai/suggest.

Build xác minh
--------------
  cd backend
  npm run build

  cd ..\frontend
  npm run build

Build kiểm tra compile/type và đóng gói frontend; nó không thay cho kiểm tra
thủ công từng luồng hay automated tests.

Database và dữ liệu
-------------------
- Backend DB: backend/prisma/dev.db theo DATABASE_URL trong backend/.env.
- Desktop DB: SQLite riêng do Tauri SQL plugin quản lý.
- Hai database chưa tự đồng bộ.
- JSON transfer hiện chỉ chuyển mục từ, không chuyển review state/history.
- Không xóa database cần giữ. Không commit .env hoặc API key.
- Migration mới thêm các trường TOEIC theo hướng giữ nguyên bản ghi cũ.

Xử lý lỗi
---------
- Không tải từ trên web: kiểm tra backend localhost:3000 và GET /words.
- Không tải từ desktop: xem thông báo; kiểm tra khởi tạo SQLite/capability.
- Không lưu desktop: kiểm tra phiên bản installer mới có sql:allow-execute.
- AI lỗi: backend phải chạy, API key/model phải đúng, mạng phải có Internet.
- Prisma generate báo EPERM: đóng Node/Nest watcher đang giữ Prisma DLL rồi chạy lại.
- Không xóa dev.db để “sửa lỗi” trước khi sao lưu.

Phạm vi chưa có
---------------
Chưa có đăng nhập, nhiều user, cloud sync, quiz, backup review history, automated
tests, analytics nâng cao hay nguồn từ điển xác minh AI. Bộ cài đã được tạo nhưng
nên tự cài và kiểm tra trên Windows trước khi phân phối cho người khác.
