BƯỚC 3: FRONTEND REACT + TYPESCRIPT
===================================

Vai trò frontend
----------------
Frontend là phần người dùng nhìn và tương tác. Nó hiển thị thư viện từ, form,
chi tiết, ôn tập và dashboard. Frontend không nên tự quyết định cấu trúc SQL;
nó gọi storage service với dữ liệu có kiểu.

Các file chính
--------------
frontend/index.html
  HTML ban đầu, có div#root nơi React được gắn vào.

frontend/src/main.tsx
  Entry point: nạp CSS, tạo React root và render App.

frontend/src/App.tsx
  Component gốc đang điều phối các màn hình, state, form, tìm kiếm, ôn tập,
  thống kê và thông báo.

frontend/src/services/vocabularyStore.ts
  Type Word/ReviewState và các hàm truy cập dữ liệu. Khi chạy trong Tauri thì
  thao tác CRUD/review dùng SQLite plugin; khi chạy web thì gọi HTTP API.

frontend/src/index.css
  Style toàn cục, layout, component và responsive.

Luồng nhập form
--------------
1. input/textarea được điều khiển bởi React state.
2. onChange cập nhật form state.
3. submit kiểm tra trường bắt buộc, chuyển danh sách nhập thành array/object.
4. saveWord gọi adapter ở vocabularyStore.ts.
5. nếu thành công, đóng modal, hiện thông báo và tải lại danh sách.
6. nếu lỗi, catch chuyển lỗi thành thông báo để người dùng xử lý.

Khái niệm React cần nắm
-----------------------
- Component: khối giao diện có thể nhận props.
- State: dữ liệu thay đổi làm React render lại.
- Props: dữ liệu/hàm cha truyền cho component con.
- useState: tạo state.
- useEffect: chạy tác vụ đồng bộ sau khi render, ví dụ tải ban đầu.
- useMemo: tránh tính lại giá trị derived khi dependency không đổi.
- Event handler: hàm phản hồi click, submit hoặc nhập liệu.
- Controlled input: value luôn lấy từ state; onChange cập nhật state.

Tìm và hiểu một chức năng
-------------------------
Mở App.tsx, tìm label nút hoặc tên handler, rồi lần đến vocabularyStore.ts.
Đừng bắt đầu bằng cách đọc toàn bộ file từ dòng đầu tới dòng cuối. Chọn một
luồng, như save hoặc review, rồi lần theo các hàm có liên quan.

Chạy và build
-------------
  cd D:\code\vocab-app\frontend
  npm ci
  npm run dev

Mở http://localhost:5173. Build production:

  npm run build

Build chạy tsc -b để kiểm tra TypeScript rồi Vite tạo bundle trong frontend/dist.
Khi xem lỗi, đọc dòng file/line trong terminal; đừng chỉ dựa vào dấu đỏ IDE.

Web hay desktop?
----------------
- Web dev dùng API NestJS. Backend phải chạy tại localhost:3000.
- Tauri desktop dùng local SQLite cho từ vựng/ôn tập. Backend vẫn cần cho AI.
- Hai database không tự đồng bộ; JSON transfer hiện chỉ chuyển từ vựng.

Desktop commands
----------------
  npm run desktop:dev       chạy Tauri trong môi trường phát triển
  npm run desktop:build     build app không tạo installer
  npm run desktop:installer tạo installer NSIS Windows

Mở rộng có chủ đích
-------------------
App.tsx còn khá nhiều trách nhiệm. Một bài tập học tốt là tách một khu vực nhỏ
thành component, ví dụ WordForm hoặc Dashboard, mà không đổi hành vi. Sau đó
build và tự thử thêm/sửa từ. Không refactor toàn bộ khi chỉ cần sửa một lỗi nhỏ.
