BƯỚC 4: BACKEND NESTJS, API VÀ DATABASE
========================================

Vai trò backend
---------------
Backend nhận request HTTP, kiểm tra input, thực hiện nghiệp vụ và lưu/đọc dữ
liệu. Web frontend gọi backend để quản lý từ và review. Desktop hiện lưu CRUD
và review ở SQLite cục bộ; backend desktop được dùng cho gợi ý AI.

Các module hiện có
------------------
- WordsModule: CRUD từ vựng.
- ReviewsModule: trạng thái, lịch đến hạn và lịch sử ôn.
- AiModule: endpoint gợi ý từ vựng.
- PrismaService: kết nối Prisma với database backend.

Luồng backend
-------------
main.ts khởi động Nest -> AppModule lắp module -> Controller nhận route
-> DTO validation -> Service nghiệp vụ -> Repository -> Prisma -> SQLite.

Controller không nên chứa truy vấn SQL hoặc logic học. Service giữ quy tắc,
Repository giữ chi tiết đọc/ghi. DTO kiểm tra hình dạng body tại API boundary.

API hiện có
-----------
Từ vựng:
  GET    /words
  GET    /words/:id
  POST   /words
  PATCH  /words/:id
  DELETE /words/:id

Ôn tập:
  GET  /reviews/due
  GET  /reviews/states
  POST /reviews/:wordId       body ví dụ: {"rating":"easy"}
  GET  /reviews/:wordId/history

AI:
  POST /ai/suggest             body gồm english, meaning tùy chọn, source tùy chọn

Cơ sở dữ liệu
-------------
backend/prisma/schema.prisma mô tả Word, ReviewState và ReviewHistory. SQLite
backend hiện ở backend/prisma/dev.db (theo DATABASE_URL trong backend/.env).
Review ghi state hiện tại và từng bản ghi lịch sử. Service dùng transaction để
lưu state/history cùng một lượt review. Migration là các thay đổi schema có thứ
tự; chạy migration deploy để cập nhật database mà không tạo lại toàn bộ bảng.

Cài, chuẩn bị database và chạy backend
--------------------------------------
  cd D:\code\vocab-app\backend
  npm ci
  npm run db:generate
  npx prisma migrate deploy
  npm run db:seed
  npm run start:dev

Backend mặc định tại http://localhost:3000. Mở /words để xem JSON. Nếu prisma
generate báo EPERM trên Windows, đóng process/watch đang giữ file Prisma DLL,
rồi thử lại. Không xóa dev.db nếu cần giữ dữ liệu.

Bật AI
------
Copy backend/.env.example thành backend/.env nếu chưa có. Đặt OPENAI_API_KEY
trong .env rồi restart backend. Không đặt key trong React, không commit .env.
AI cần Internet và API usage được bật cho key. Xem docs/TOEIC_AI.md.

Validation và duplicate
-----------------------
main.ts bật ValidationPipe toàn cục. DTO dùng class-validator để kiểm tra input.
WordsService trim trường cần thiết, chặn từ tiếng Anh trùng và trả lỗi HTTP có
ý nghĩa. Controller có ParseIntPipe chuyển id URL thành số và báo lỗi nếu sai.

Build và kiểm tra
-----------------
  npm run build

Nest compile TypeScript vào backend/dist. Đây là kiểm tra compile, không thay thế
việc thử endpoint. Nếu frontend không tải data, kiểm tra backend đang chạy và
thử trực tiếp http://localhost:3000/words.

Khái niệm học được
-----------------
- REST: tài nguyên words/reviews được thao tác theo HTTP methods.
- DTO/validation: boundary ngăn input tùy ý đi sâu vào nghiệp vụ.
- Dependency injection: Nest tạo và cấp các service phụ thuộc.
- ORM: Prisma tạo truy vấn có type từ schema.
- Transaction: nhóm các thao tác database để lưu review nhất quán.
- Migration: thay đổi cấu trúc database theo phiên bản.
- Environment variable: cấu hình/key không hard-code vào source.
