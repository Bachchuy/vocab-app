HƯỚNG DẪN: frontend/src/index.css

CSS toàn cục cho giao diện Lexicon: palette/font, sidebar, page layout, cards,
form/modal, dashboard, detail, flashcards, toast và responsive breakpoints.

File này chỉ điều khiển cách hiển thị, không lưu dữ liệu và không gọi API. Khi
sửa class, kiểm tra cả cửa sổ rộng và hẹp; tránh làm vỡ modal hoặc scroll. Tên
class thường gắn với component/khối tương ứng trong App.tsx.
