HƯỚNG DẪN: frontend/package.json

Manifest frontend khai báo scripts và dependencies.
- npm run dev: Vite dev server.
- npm run build: tsc -b rồi vite build.
- npm run preview: xem bundle production.
- npm run desktop:dev: chạy Tauri dev.
- npm run desktop:build: build desktop không bundle installer.
- npm run desktop:installer: tạo NSIS Windows installer.

Dependencies gồm React/React DOM; dev tools gồm TypeScript, Vite, Tauri CLI và
plugin React. Dùng npm install <package> trong frontend để thêm thư viện; npm
cập nhật lock file. Không viết logic ứng dụng trong package.json.
