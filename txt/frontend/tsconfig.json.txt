HƯỚNG DẪN: frontend/tsconfig.json

Cấu hình TypeScript cho frontend. strict giúp kiểm tra kiểu; JSX dùng React
runtime; DOM libs cung cấp kiểu browser APIs. Project build chạy tsc -b rồi Vite.

Nếu build có lỗi, đọc đường dẫn và dòng trong terminal, sau đó sửa kiểu/logic.
Không tắt strict chỉ để làm mất thông báo. Cấu hình hiện có thể chia thành các
file tsconfig app/node; đọc toàn bộ cấu hình thật khi cần chỉnh compiler.
