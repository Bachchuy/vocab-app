HƯỚNG DẪN: backend/src/main.ts

Entry point backend. NestFactory tạo app từ AppModule; ValidationPipe toàn cục
kiểm tra DTO, whitelist field và transform kiểu; enableCors cho frontend dev;
app.listen mở HTTP server (mặc định port 3000 hoặc biến PORT).

Luồng: main -> AppModule -> modules/controllers -> services. File này dùng để
bootstrap cấu hình chung. Không viết nghiệp vụ từ vựng hoặc truy vấn database ở đây.
