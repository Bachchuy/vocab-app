HƯỚNG DẪN: backend/nest-cli.json

Nest CLI dùng file này để biết source backend nằm ở đâu và cấu hình scaffold/build.
Các script thực tế xem trong backend/package.json. Lệnh thường dùng:
  npx nest generate module feature
  npx nest generate controller feature
  npx nest generate service feature

Feature đã có: words, reviews, ai. Khi thêm feature, tạo module riêng rồi đăng ký
trong AppModule. CLI config không chứa logic nghiệp vụ.
