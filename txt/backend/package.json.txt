HƯỚNG DẪN: backend/package.json

Đây là manifest của backend NestJS: khai báo dependencies và lệnh chạy.
Scripts hiện có:
- npm run build: compile backend vào dist.
- npm run start / start:dev / start:prod: chạy server thường, watch hoặc production.
- npm run db:generate: sinh Prisma Client.
- npm run db:migrate: chạy migration phát triển.
- npm run db:seed: nạp starter data.
- npm run db:status: xem trạng thái migration.

Dependencies đáng chú ý: NestJS, Prisma Client, class-validator,
class-transformer, TypeScript. package-lock.json do npm quản lý; không sửa tay.
Thêm package bằng npm install <tên> trong thư mục backend.
